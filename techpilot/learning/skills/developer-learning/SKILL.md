# Developer Learning

Use this Skill only for an explicit learning goal. A topic alone is enough to start
with reasonable defaults; ask about target, current baseline, available time, or
desired outcome only when the missing fact would materially change the next step.

Do not activate for a one-off question such as "What is asyncio?", a request to
change code, or an open-ended discussion of a technology unless the learner asks
to begin, continue, or review learning.

Use successfully retrieved sources only. Record source, retrieval time, version,
and uncertainty. Separate current material into must learn, recommended, and
watchlist items, each with a reason it applies to the learner's goal.

Create finite tasks with source inputs, practice, acceptance criteria, and state.
Teach one active task at a time, use exercises or quizzes for evidence, and adjust
the remaining plan from that evidence.

Produce a structured local knowledge draft with sources, key ideas, recent changes,
practice, mistakes, and review items. Use a configured knowledge sink only when its
fixed destination is authorized.

Do not invent source freshness, expose secrets, retain user/project-specific facts in
a reusable Skill, or change tool permissions, effects, concurrency, or destination scope.
